# Tick

A fast, native GNOME client for Todoist, written in Rust with GTK4 and libadwaita.

Tick renders from a local cache before touching the network, so it opens instantly,
and it keeps working offline.

> Tick is an independent project and is not affiliated with Doist.

## Install

```sh
just install
```
